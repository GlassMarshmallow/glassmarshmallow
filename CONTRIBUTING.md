# Contributing to GlassMarshmallow

Thanks for helping. Issues and pull requests are welcome, in English or Spanish.

## Before you start

- **Bugs:** open an issue with the steps to reproduce it, what you expected and what happened, the browser and
  whether it happens in light mode, dark mode or both.
- **New components or big changes:** open an issue first to talk about it, so no work is wasted.
- **Security problems:** do not open an issue; follow [SECURITY.md](SECURITY.md).

## Setup

```sh
git clone https://github.com/GlassMarshmallow/glassmarshmallow.git
git clone https://github.com/GlassMarshmallow/glassmarshmallow-icons.git
cd glassmarshmallow && npm install
npm --prefix site install
npm run site            # documentation at http://localhost:4500
```

The two repositories go next to each other: the documentation uses the icons from `../glassmarshmallow-icons`.

## How the code is organized

- `css/` is the source (plain CSS, no Sass). `dist/` is generated with `npm run css`; never edit it by hand.
- `css/utilities-layout.css` is generated by `build/gen-utilities.mjs` (`npm run utilities`).
- `js/` has one optional script per component, with no dependencies, and its `.d.ts`.
- `bin/glassmarshmallow.mjs` is the `npx glassmarshmallow build` command for arbitrary values.
- `site/` is the documentation (Angular). Pages are Markdown in `site/public/content/docs/{en,es}`; every page
  exists in both languages.

[AGENTS.md](AGENTS.md) has the full rules (they are the same for people and for AI agents).

## Rules for changes

- **Names:** the `gm-` prefix; components with BEM (`.gm-card`, `.gm-card__title`, `.gm-card--link`).
- **Colors** only from the `--gm-` variables, in light and dark mode.
- **Sizes** in `rem`, `em` or `%` (thin borders, shadows, blurs and focus outlines can stay in `px`).
- **Accessibility:** WCAG 2.2 AA in both modes, AAA when possible: text 4.5:1 (aim for 7:1), borders and icons
  3:1, 44 × 44 px targets, visible focus, keyboard use and `prefers-reduced-motion`.
- **Docs:** every new class or component gets its page or section, in English and Spanish, with an example.

## Checks

Run them before opening a pull request; GitHub Actions runs them too:

```sh
npm test                          # the CSS builds, is inside the layer and every class in the docs examples exists
npm --prefix site run build:site  # builds the documentation
npm run test:a11y                 # axe-core on every page, light and dark, desktop and mobile
```

## Commits

[Conventional Commits](https://www.conventionalcommits.org/): `type(scope): description`, for example
`fix(button): …`, `feat(utilities): …`, `docs(install): …`. Add the change to the **Unreleased** part of
[CHANGELOG.md](CHANGELOG.md).
