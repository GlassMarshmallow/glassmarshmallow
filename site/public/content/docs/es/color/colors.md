# Paleta

Una paleta de ocho colores pastel, además de negro, blanco y grises, que se usan sólidos o vidriados. Esta página los presenta; las siguientes páginas de esta sección explican cómo usarlos.

> **Accesibilidad:** todas las combinaciones cumplen **WCAG 2.2 AA** y la mayoría llegan a **AAA**. El detalle está al final de la página.

| --- | --- | --- | --- |

En modo oscuro, el color de texto es el propio pastel.

## Escalas

Cada color tiene 13 tonos, del `025` (casi blanco) al `975` (casi negro), calculados a partir de su pastel: el mismo matiz con distinta luminosidad. El tono marcado con **★ pastel** es el pastel y **Aa texto**, el tono de texto en modo claro. Debajo de cada tono, su contraste sobre blanco (□) y sobre negro (■): a partir de 4,5 sirve para texto.

Son variables CSS, como los colores de Bootstrap: `var(--gm-sky-500)`, `var(--gm-coral-800)`, `var(--gm-gray-050)`… No hay una clase para cada tono, para que el archivo no crezca.

## Cómo usarlos

Cada color se usa con estas clases:

- [Color de texto](/docs/color/text): el texto en un color, con `.gm-text-sky`.
- [Fondo](/docs/color/background): un fondo sólido, con `.gm-bg-sky`.
- [Modo claro y oscuro](/docs/color/color-modes): modo claro u oscuro en una parte de la página, con `data-theme`.
- [Tema](/docs/color/theme): sólido, vidriado o texto de una vez, con `.gm-theme-sky` y `.gm-theme-solid`, `.gm-theme-glass` o `.gm-theme-text`.

## Variables CSS

Cada color tiene tres variables para usarlo en tu propio CSS:

```css
--gm-sky: #5cdfeb;          /* el pastel */
--gm-sky-rgb: 92 223 235;   /* el mismo color en canales RGB, para darle transparencia */
--gm-sky-text: #20747b;     /* el tono de texto (en oscuro, el propio pastel) */
```

Los valores del vidriado también son variables: `--gm-glass-alpha`, `--gm-glass-border-alpha`, `--gm-glass-radius`, `--gm-glass-blur` y `--gm-glass-shadow`.

## Accesibilidad

| Uso | Contraste | Nivel |
| --- | --- | --- |
| Texto negro sobre el color sólido | de 7,8:1 a 13,3:1 | AAA |
| Texto sobre el vidriado (claro y oscuro) | unos 14:1 | AAA |
| Texto de color, modo oscuro | de 9,7:1 a 16,6:1 | AAA |
| Texto de color, modo claro (tonos 800 y 900) | 7:1 o más | AAA |
| Texto sobre los grises (sólido) | 7:1 o más, salvo `gray-500` (5,2:1) y `gray-600` (6:1) | AAA (esos dos, AA) |
| Texto gris (`.gm-theme-text`) | 7:1 o más | AAA |

- **Nunca texto blanco sobre el pastel sólido:** se queda por debajo de 2,2:1.
- El borde del vidriado es suave. Las tarjetas, avisos y botones con texto no necesitan más, pero los controles de formulario que se reconocen por su contorno (campos, casillas, interruptores) usan el borde gris del framework, que llega a 3:1.
- No indiques un estado solo con el color: éxito, aviso y error llevan siempre un icono o un texto.
- El vidriado deja ver el fondo. Sobre una foto o colores fuertes, mide el contraste del texto en el sitio donde lo uses.
