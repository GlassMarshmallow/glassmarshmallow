# Palette

A palette of eight pastel colors, plus black, white and grays, used solid or glazed. This page lists them; the next pages of this section explain how to use them.

> **Accessibility:** every combination meets **WCAG 2.2 AA**, and most of them reach **AAA**. The details are at the end of the page.

## Palette

| Color | Name in the classes | Pastel | Text color (light mode) |
| --- | --- | --- | --- |
| Sky | `sky` | `#5CDFEB` | `#02464B` |
| Blue | `blue` | `#8AB4FF` | `#003290` |
| Lavender | `lavender` | `#B9A3FF` | `#5F23B8` |

In dark mode, the text color is the pastel itself.

## Scales

Each color has 13 tones, from `025` (almost white) to `975` (almost black), calculated from its pastel: same hue, different lightness. The tone marked **★ pastel** is the pastel and **Aa text** is the text tone in light mode. Under each tone, its contrast on white (□) and on black (■): 4.5 or more is valid for text.

They are CSS variables, like Bootstrap's colors: `var(--gm-sky-500)`, `var(--gm-coral-800)`, `var(--gm-gray-050)`… There are no classes for each tone, so the file stays small.

## How to use them

Each color is used with these classes:

- [Colors](/docs/color/text): the text in a color, with `.gm-text-sky`.
- [Background](/docs/color/background): a solid background, with `.gm-bg-sky`.
- [Light and dark mode](/docs/color/color-modes): light or dark mode in one part of the page, with `data-theme`.
- [Theme](/docs/color/theme): solid, glazed or text in one go, with `.gm-theme-sky` and `.gm-theme-solid`, `.gm-theme-glass` or `.gm-theme-text`.

## CSS variables

Each color has three variables, so you can use it in your own CSS:

```css
--gm-sky: #5cdfeb;          /* the pastel */
--gm-sky-rgb: 92 223 235;   /* the same color in RGB channels, for transparency */
--gm-sky-text: #20747b;     /* the text tone (the pastel itself in dark mode) */
```

The glass values are variables too: `--gm-glass-alpha`, `--gm-glass-border-alpha`, `--gm-glass-radius`, `--gm-glass-blur` and `--gm-glass-shadow`.

## Accessibility

| Use | Contrast | Level |
| --- | --- | --- |
| Black text on the solid color | 7.8:1 to 13.3:1 | AAA |
| Text on glass (light and dark) | about 14:1 | AAA |
| Colored text, dark mode | 9.7:1 to 16.6:1 | AAA |
| Colored text, light mode (tones 800 and 900) | 7:1 or more | AAA |
| Text on the grays (solid) | 7:1 or more, except `gray-500` (5.2:1) and `gray-600` (6:1) | AAA (those two, AA) |
| Gray text (`.gm-theme-text`) | 7:1 or more | AAA |

- **Never use white text on the solid pastel:** it stays below 2.2:1.
- The glass border is soft. Cards, alerts and buttons with text don't need more, but form controls that are recognized by their outline (fields, checkboxes, switches) use the framework's gray border, which reaches 3:1.
- Don't show a state with color alone: success, warning and error always come with an icon or a text.
- Glass lets the background show through. Over a photo or strong colors, measure the contrast of the text where you use it.
