# Skills

Step-by-step guides (`<name>/SKILL.md`) that teach AI coding agents how to do common GlassMarshmallow tasks, as Bootstrap does in `twbs/bootstrap/skills`:

| Skill | What it does |
| --- | --- |
| [`install`](install/SKILL.md) | Add GlassMarshmallow to a project: CSS, icons, Montserrat, color mode and optional scripts |
| [`customize-colors`](customize-colors/SKILL.md) | Change colors in light and dark mode with the `--gm-` variables, keeping AA/AAA contrast |
| [`create-component`](create-component/SKILL.md) | Add a new component to the framework following its design and accessibility rules |

The whole documentation is also available for AI tools at `/llms.txt` (index) and `/llms-full.txt` (everything in one file) on the docs site.
